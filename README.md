## 🚀 Key Features

- **⚡ 3-Second Interactive Lead Simulator**: Test live inbound Meta Ad form submissions with real-time pipeline execution.
- **💬 Instant WhatsApp VIP PDF Brochure**: Delivers floorplans & digital property brochures via Meta WhatsApp Cloud API in under 1.4 seconds.
- **📢 Real-Time Broker Sales Team Alert**: Triggers Telegram sound notifications to sales team channels with direct `tel:` 1-click calling links in under 2.1 seconds.
- **📊 Google Sheets / CRM Live Auto-Sync**: Appends lead records to live databases in under 2.4 seconds without manual CSV export.
- **🌐 Dual Currency Engine**: Seamless real-time switcher for **🇺🇸 USD ($)** and **🇮🇳 INR (₹)** markets.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19 + Vite 8 + TailwindCSS 4 + Lucide Icons + Canvas Confetti
- **Deployment**: Docker + Nginx (Coolify 1-Click Ready)
- **Backend Integrations**: n8n Webhook Engine, Meta WhatsApp Business Cloud API, Telegram Bot API, Google Sheets REST Webhooks

## 🐳 Coolify 1-Click Deployment Guide

1. In your Coolify dashboard, select **New Resource** ➔ **GitHub Repository**.
2. Point to repository: `https://github.com/mangalcool222/automation-client-demo`
3. Branch: `main`
4. Destination Domain: `demo.gtm.trackkaroai.com` (or `demo.trackkaroai.com`)
5. Click **Deploy**. (Root `Dockerfile` & `nginx.conf` are pre-configured).
